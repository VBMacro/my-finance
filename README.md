# My Finance PWA V1

A local/offline personal finance PWA.

Features:
- Master categories matching the user's budgeting categories
- Budget cycle 29 -> 28
- Rolling balance; balance never resets
- Add, edit, delete transactions
- History filters
- Manage categories/budgets
- LocalStorage persistence
- Installable as a PWA where supported

## Important
This is a browser/PWA version. For reliable "Add to Home screen" installation, host the folder on HTTPS (or localhost during development). Opening index.html directly may work for basic testing but PWA installation/service-worker features can be restricted by the browser.

Default initial balance: Rp 28,803,000.
